
MANUAL SOBRE COMO MODIFICAR LA PÁGINA: --------------------

Inicio:
[ ] Mandar "Nombre START" al grupo de whatsapp (Paula START)
[ ] Abrir terminal 
[ ] git pull

Edición:
[ ] Hacemos cambios en el código
[ ] Vemos los cambios en tiempo real con Live Server

Guardado:
[ ] Abrir terminal 
[ ] git add .
[ ] git commit -m "Autor. Fecha. Página. Descripción del cambio"
[ ] git push -u origin main

Subida a la Página:
[ ] Vemos los cambios online en Github
[ ] Enlazamos con FileZilla
[ ] Subimos los cambios con FileZilla a CPanel
[ ] Vemos la actualización online en la página oficial de OMA Córdoba

Finalización:
[ ] Mandar "Nombre END" al grupo de whatsapp (Paula END)

CONECTAR CON SASS:
    1. Tener Node.js y npm instalados
    2. Parate en la carpeta raíz del proyecto
    3. Crear el package.json con el comando "npm init -y"
    4. Instalar Sass con el comando "npm install --save-dev sass"
    5. Configurar package.json:
        "scripts": {
            "sass": "sass scss/estilos.scss CSS/estilos.css",
            "watch": "sass --watch scss/estilos.scss:CSS/estilos.css"
        }
    6. Compilar con el comando "npm run watch"
